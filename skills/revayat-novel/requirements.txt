# Python 3.10 or newer. CI runs 3.10, 3.13 and 3.14 on Linux, macOS and Windows
# — the oldest and newest supported, plus the one someone installing Python
# today gets. Verified rather than assumed: every script parses under
# `ast.parse(..., feature_version=(3, 10))`.
#
# **3.10 reaches end of life in 2026-10** (python.org developer guide). After
# that a reader on it gets no further CPython security fixes. The floor is kept
# at 3.10 anyway, because several current distro images still ship it as the
# system Python and this skill is meant to run on whatever the reader has.
# Raising it to 3.11 is a two-line change: this comment and `ruff.toml`'s
# `target-version`, plus the CI matrix.

# Two sibling files answer different questions. `requirements-optional.txt`
# declares the wheels two stages need and the rest of the pipeline does without.
# `../../constraints-ci.txt` is the exact set the build was checked against — the
# floors below are the range the skill supports, which is not the same claim.
# What makes the floors a tested claim rather than a stated one is
# `dependency-floors.json`, which holds the lowest release inside each floor's own
# series, plus the two lanes that read it: `supported-range.yml` installs that set
# exactly and runs the suite on it, and `dependency-audit.yml` asks the advisory
# database about the same set. One list, two questions.

# Core — required for every run.
# 1.24.3 and not 1.24: PyMuPDF published the module name `pymupdf` in 1.24.3,
# and every release before it can only be imported as `fitz`. This project
# imports `pymupdf`, so `>=1.24` named versions that cannot run it at all —
# measured on 3.10: 1.24.0, 1.24.1 and 1.24.2 all raise ModuleNotFoundError,
# 1.24.3 imports. The floor was never installed by any job, which is why a
# false one survived; the floors lane installs it now.
pymupdf>=1.24.3          # PDF text, geometry and original image bytes
python-docx>=1.1         # DOCX reading and writing
beautifulsoup4>=4.12     # EPUB (XHTML) parsing
# Security floors: current XML entity and image-decoder fixes; Python 3.10 supported.
lxml>=6.1.3              # OOXML manipulation (also a python-docx dependency)
pillow>=12.3.0           # removing a colour watermark from scanned pages

# Development only.
# 9.0.3 fixes GHSA-6w46-j5rx-g56g and still supports Python 3.10.
# This is a security floor, separate from CI's routine version pin.
pytest>=9.0.3
pytest-timeout>=2.3
