# Управление, падежи, согласование

Ошибки этого класса стилем не смягчаются. Читатель считывает их как неграмотность автора и дальше не верит ничему.

---

## 1. Предлоги и падежи, на которых спотыкаются

| Правильно | Неправильно |
|---|---|
| согласно приказу, договору, расписанию | согласно приказа |
| вопреки прогнозу, благодаря помощи, наперекор совету | вопреки прогноза |
| оплатить проезд (что) / заплатить за проезд (за что) | оплатить за проезд |
| по приезде, по окончании, по прибытии, по завершении | по приезду, по окончанию |
| скучаю по вам | скучаю за вами |
| преимущество перед конкурентом, превосходство над соперником | преимущество над |
| отличие от версии 2, разница между версиями | отличие с версией |
| уделять внимание документации / обращать внимание на документацию | уделять внимание на |
| играть роль / иметь значение | играть значение |
| опираться на факты / основываться на фактах | опираться на фактах |
| указывать на ошибку, свидетельствовать об ошибке | указывать об ошибке |
| в течение недели (предлог, всегда -е) | в течении недели |
| вследствие сбоя (предлог) / в следствии по делу (существительное) | в следствии сбоя |
| в продолжение разговора | в продолжении разговора |
| ввиду ремонта / иметь в виду | в виду ремонта |
| прийти, идти, найти | придти, притти |

Приём проверки: подставь вопрос. «Согласно чему?» — дательный. «Вопреки чему?» — дательный. «Благодаря чему?» — дательный.

## 2. Слова, которые путают

- **Надеть** что-то на себя или на кого-то, **одеть** кого-то. Надеть пальто — одеть ребёнка.
- **Представить** (познакомить, предъявить) и **предоставить** (дать в распоряжение). Представить отчёт комиссии — предоставить отпуск.
- **Эффектный** (производит впечатление) и **эффективный** (даёт результат).
- **Экономный** (человек), **экономичный** (устройство), **экономический** (относящийся к экономике).
- **Крайний** и **последний**: очередь крайняя, раз в жизни — последний.
- **Довлеть** означает «быть достаточным». Проще не употреблять.
- **Нелицеприятный** означает «беспристрастный». Тоже проще обойти.

## 3. Степени сравнения

Двойная степень — грубая ошибка: «более лучше», «самый наилучший», «более выше», «наиболее оптимальный». Либо «лучше», либо «более хороший». «Оптимальный» уже превосходная степень и усилений не принимает. То же с «единственный», «уникальный», «максимальный», «идеальный».

## 4. Согласование сказуемого

- **Аббревиатуры** согласуются по опорному слову: МВД сообщило (министерство), ЕС принял (союз), США приняли (штаты), ООН приняла (организация).
- **Названия в кавычках**: «Роснефть» сообщила, но компания «Роснефть» сообщила; банк «Точка» открыл.
- **Количественные обороты** допускают оба числа, и выбор осмысленный. Единственное — про совокупность и итог: «пришло двадцать человек». Множественное — про отдельных участников: «двадцать человек написали в поддержку».
- **«Более / свыше / около»**: «Более 20 сотрудников подписали письмо» — множественное, когда люди действуют.
- **«Ряд», «часть», «большинство»**: «Большинство проголосовало» (как целое), «Большинство сотрудников пришли пешком» (по отдельности).

## 5. Числительные в косвенных падежах

Склоняются обе части: с пятьюстами рублями, около полутора тысяч, к обоим файлам (м. и ср. род) и к обеим папкам (ж. род), в две тысячи двадцать шестом году — здесь склоняется только последнее слово.

Практический выход: громоздкую конструкцию перестрой. «Отчёт по 1 587 обращениям» вместо «отчёт по тысяче пятистам восьмидесяти семи обращениям».

## 6. Причастия и деепричастия

- **Деепричастие относится к субъекту сказуемого.** «Используя этот метод, результаты улучшаются» — деепричастие осталось без хозяина. Чинится подлежащим («Используя этот метод, мы улучшаем результаты») или придаточным («Если использовать этот метод, результаты улучшаются»).
- **Нанизывание причастий.** Два причастных оборота подряд читаются с трудом, три не читаются вовсе: «данные, полученные из системы, обрабатывающей запросы, поступающие от клиентов». Разбивай на предложения, меняй причастие на глагол, вводи «который» — не больше одного на предложение.
- **-вш- и -ущ- рядом** дают шипение. «Сообщающий о происходящем» — переписать.
- **Причастие будущего времени не существует.** «Сотрудник, сделающий отчёт» — ошибка. «Тот, кто сделает отчёт».

## 7. Однородные члены

Однородными могут быть сопоставимые вещи в одинаковых формах. «Он любит футбол, читать и по вечерам гулять» — разнобой. Второй частый случай — общее управление у слов с разным управлением: «уход и контроль за оборудованием» (уход за, контроль над). Чинится повтором: «уход за оборудованием и контроль над ним».

## 8. Проверка, когда норма неочевидна

Сочетаемость и падеж проверяются по Национальному корпусу русского языка (ruscorpora.ru): ищи конструкцию целиком и смотри, встречается ли она у авторов. Полсотни примеров у разных авторов — сочетание живое. Три примера из блогов — придумано.

Спорные случаи управления — по словарю Розенталя «Управление в русском языке».
